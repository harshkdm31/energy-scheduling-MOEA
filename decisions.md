# Research Decisions

| Decision ID | Date | Area | Decision Summary | Rationale & Alternatives Considered | Approved By |
|---|---|---|---|---|---|
| DEC-001 | 2026-10-27 | Chromosome Encoding | Use 0-indexed integer encoding `[0, m-1]` for chromosome mapping | Direct alignment with Python and NumPy zero-indexing semantics; alternatives like 1-indexed `[1, m]` require continuous offset translation in array operations. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-002 | 2026-10-27 | Power Modeling | Active power formula $P_j = \kappa s_j^\alpha \epsilon_j$ with $\kappa=1.0$ across $\alpha \in \{1, 2, 3\}$ and noise $\epsilon_j \sim \text{Uniform}(0.8, 1.2)$ | Represents polynomial power scaling with speed under realistic sub-linear/linear/super-linear dynamic energy regimes while incorporating hardware variance; alternatives like constant speed-independent power or deterministic powers fail to reflect realistic CMOS scaling and heterogeneity. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-003 | 2026-10-27 | Data Contract | Standard JSON instance schema agreement capturing problem parameters ($n, m, \alpha, \kappa, \text{seed}, w, s, p$) and instance descriptors ($\rho_s, \rho_e, r(s, e)$) | Human-readable, portable, language-agnostic schema with built-in analytical metrics ensuring full reproducibility and easy validation across algorithmic baselines; alternatives like CSV/NPZ lack metadata bundling and schema self-documentation. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-004 | 2026-10-27 | Deterministic Tie-Breaking | Lowest-machine-index tie-breaking convention across all heuristic baselines (`solve_mct`, `solve_energy_greedy`, `solve_weighted_greedy_sweep`) | Guarantees strict reproducibility and eliminates stochastic drift in baseline benchmarks; alternatives like random tie-breaking introduce non-deterministic evaluation variance. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-005 | 2026-10-27 | Baseline Algorithms | LPT task ordering and analytical lower bound ($LB_C, LB_E$) scalarization for the weighted-greedy sweep ($g_j = \lambda \frac{C_j + w_i/s_j}{LB_C} + (1-\lambda)\frac{w_i e_j}{LB_E}$) | LPT placement yields effective makespan packing; normalization by exact lower bounds ensures commensurate scaling between makespan and energy across $\lambda \in [0, 1]$; alternatives like unnormalized objectives produce biased trade-off distributions. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-006 | 2026-10-27 | Genetic Operators | Energy-Aware Mutation fallback rule (uniform random reset across all $m$ machines when $\mathcal{M}_{\text{better}} = \emptyset$) | Preserves exploratory genetic diversity and prevents mutation stagnation when tasks already reside on optimal-efficiency machines; alternatives like skipping mutation reduce search pressure, while deterministic no-ops degrade diversity. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-007 | 2026-10-27 | Evolutionary Optimization | NSGA-II integer chromosome encoding $[0, m-1]^n$, PointCrossover, duplicate elimination, and evaluation budget protocol ($B(n)=200n$) | Standardizes computational effort proportionally with problem size $n$ while guaranteeing strictly integer alleles and exact evaluation invariants; alternatives like continuous relaxation introduce discretization bias. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-008 | 2026-10-27 | Statistical Analysis | Non-parametric statistical protocol: Paired Wilcoxon signed-rank test with Holm-Bonferroni multi-comparison correction, reporting Median + IQR | Metric distributions across stochastic MOEA runs exhibit skewness and outliers violating normality; paired tests over matching seeds control instance variance, Holm-Bonferroni guards family-wise error without extreme conservative bias, and Median+IQR prevents distorted dispersion reporting; parametric t-tests/ANOVA inflate Type I error on non-normal distributions. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-009 | 2026-10-27 | Result Persistence | Raw uncompressed/compressed `.npz` output schema contract before pooled normalization | Storing raw Pareto objective vectors (`non_dominated_F`), integer schedules (`non_dominated_X`), evaluation count, and timing allows lossless post-hoc pooled reference-point normalization and indicator re-computation; storing pre-normalized values destroys raw data provenance and prevents indicator updates. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-010 | 2026-10-27 | Evaluator Invariant Verification | Independent verification contract for evaluator invariants ($f_1 \ge LB_C$, $f_2 \ge LB_E$) via brute-force enumeration on $3^8 = 6,561$ search space | Combinatorial exhaustive evaluation across all $m^n = 3^8 = 6,561$ schedules rigorously proves zero lower bound violations, verifies exact analytical lower bound attainment ($\min f_2 = LB_E$), and validates that the single-objective energy greedy anchor strictly belongs to the true Pareto front $\mathcal{P}^*$; spot-checking random assignments risks missing boundary violations. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-011 | 2026-10-28 | Hyperparameter Freeze | Freeze population size ($N_{\text{pop}} = 100$), evaluation budget contract ($B(n) = 200n$), and strict seed isolation (development seeds `[101, 102, 103]` vs. 30 independent evaluation seeds `[201, ..., 230]`) | Prevents data snooping and hyperparameter overfitting; developmental tuning/debugging strictly restricted to dev seeds, guaranteeing statistical independence and unbiased performance estimates during final evaluation; alternatives like shared seeds or adaptive budgets violate replication validity. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-012 | 2026-10-28 | Experimental Staging | Two-stage experimental execution protocol: Stage 1 Core ($n=200, m=8$ across $\alpha \in \{1.0, 2.0, 3.0\}$ with $B(n)=40,000$) and Stage 2 Scale (Small $50 \times 4, B(n)=10,000$ and Large $500 \times 16, B(n)=100,000$ at base exponent $\alpha=2.0$) | Deconstructs experimental matrix into core power regime exploration and dedicated dimensional scalability benchmarking; ensures computational feasibility while covering sub-linear, linear, and super-linear regimes; alternatives like full grid factorial over all sizes and alphas incur prohibitive compute with redundant statistical signals. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-013 | 2026-10-28 | Batch Orchestration | 30-seed production batch orchestration harness with CLI smoke-test support (`--smoke-test`) for continuous integration | Ensures full 30-seed test matrix execution for final benchmark results while enabling rapid, non-flaky sub-second automated verification in CI pipelines; alternatives like manual shell scripts lack invariant checks, and running full budgets in CI causes excessive build timeouts. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-014 | 2026-10-28 | Hypothesis Testing Protocol | Formal hypothesis testing family definition evaluating Hypervolume ($r = 1.1 \times \max F$) with paired two-tailed Wilcoxon signed-rank tests, Holm-Bonferroni step-down correction at $\alpha=0.05$, Cliff's delta effect sizes, and Median + IQR reporting | Controls family-wise error rate across multi-algorithm multi-exponent comparisons without inflated Type I error; pairing over identical random seeds isolates algorithm variance from instance stochasticity; Median + IQR captures non-Gaussian dispersion truthfully; parametric ANOVA/t-tests violate non-normality assumptions of bounded multi-objective indicators. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-015 | 2026-10-28 | Visualization Standards | Headless rendering architecture using Matplotlib `Agg` backend with analytical lower-bound guideline overlays ($LB_C, LB_E$), consistent color palettes, and 300 DPI rasterization | Eliminates GUI and display server dependencies in CI/remote environments while guaranteeing publication-grade visual clarity and objective grounding against theoretical lower bounds; alternatives like GUI backends (`TkAgg`, `Qt5Agg`) fail in headless Docker/CI systems. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
| DEC-016 | 2026-10-28 | Report Synthesis Template | Automated empirical research summary synthesis template integrating raw data provenance, analytical invariant guarantees, non-parametric hypothesis tables, and high-DPI Pareto figures | Bridges raw benchmark data and publication-ready documentation into a reproducible, self-contained Markdown/LaTeX synthesis report; alternatives like manual report assembly are error-prone and fail to maintain continuous synchronization with ongoing experimental runs. | Mohammad Ayaan (moonylit), Harsh Kadam (harshkdm31) |
